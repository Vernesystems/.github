### How we build

**In the room, not over the wall.**<br>
We work inside the operation, next to the people whose day the software changes.

**Evidence before opinion.**<br>
Claims carry sources, models carry evals, and every decision leaves a trail.

**Built to be handed over.**<br>
It is done when the people who use it can run it without us.
